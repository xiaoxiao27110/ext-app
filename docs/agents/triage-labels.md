# Triage labels

The engineering skills use five canonical triage roles. This file maps those roles to the Chinese labels used in this repository.

| Canonical role | Repository label | Meaning |
| --- | --- | --- |
| `needs-triage` | `待分诊` | Maintainer needs to evaluate the issue |
| `needs-info` | `待补充信息` | Waiting for the reporter to provide more information |
| `ready-for-agent` | `可由 Agent 处理` | Fully specified and ready for an agent |
| `ready-for-human` | `需人工处理` | Requires human judgment or implementation |
| `wontfix` | `不处理` | Will not be actioned |

When a skill names a canonical role, use the corresponding repository label from this table.
